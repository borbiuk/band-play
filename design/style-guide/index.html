Band Play style guide

One light, soft visual language for the popup, the downloads page, the elements on Bandcamp and the store banners. Brand color is Bandcamp Aqua #1DA0C3.

Principles

  • Light only. White or very light aqua backgrounds, like Bandcamp itself. No dark theme.
  • Soft, in the spirit of Arc. Rounded shapes, thin lines, calm shadows, one clear primary action per area.
  • Transparency with a reason. Glass is used for bars that content scrolls under (popup header and footer, downloads header, batch bar). Never for body text surfaces.
  • Bandcamp first on Bandcamp. Elements injected into Bandcamp pages copy its flat, small, aqua-link look and only borrow our corner radius, primary color and shadow. The Bandcamp player and our feed player are not restyled.
  • Never color alone. Every status has an icon and a label. Every text pair passes WCAG AA (see Color).

Logo

The mark is the Band Play mask on the Bandcamp-shaped slab, in Bandcamp Aqua. Source: design/logo/logo.svg.

Sizes

Use logo-16/32/48/128.png in the manifest and the toolbar. Use logo-store-128.png as the store listing icon (96 px artwork with 16 px transparent padding). The mark is a flat shape: at 16 px the eyes and mouth merge into the black mask, which is expected.

Clear space and minimum size

  • Keep clear space of one mask height (x) on every side.
  • Minimum size: 16 px wide in the toolbar, 24 px wide in the UI.
  • Place it on white or very light aqua, or on the aqua gradient of the banners.

Use glass only for bars that content scrolls under. The page behind needs a soft aqua glow so the blur is visible. The batch bar on Bandcamp uses blur 12 px on a 94% white fill so it stays readable over any cover.

  • The bar sits bottom right, 96 px above the bottom so it clears Bandcamp's player.
  • No batch UI on the wishlist. The feed player and Bandcamp's own player are never restyled.

Motion and accessibility

  • Motion: 120-180 ms ease for hover, switch and chevron; 400 ms for progress fills. Nothing moves for decoration. prefers-reduced-motion turns all transitions off.
  • Focus: always visible, the 2 px aqua ring with a 2 px white gap (--focus). Never remove an outline without a replacement.
  • Targets: at least 28 px, 32 px for icon buttons. Hover-only controls are also shown on focus.
  • Keyboard: tabs use arrow keys, Home and End. Dialogs are native <dialog> opened with showModal() (Escape closes, focus is trapped). Switches are checkboxes with role="switch".
  • Status: icon plus label plus color. Live counters use aria-live="polite".
  • Browsers: Chrome and Firefox 128+. :has() and backdrop-filter have fallbacks (frame becomes outline-only, bars become solid white).

Voice

  • English, sentence case, short. Verbs on buttons: "Clear history", "Retry failed", "Download 3".
  • Say what happens and what it costs: "Stops the display from sleeping and drains battery".
  • Units after numbers with a space: "10 sec", "184 MB", "18.4 MB/s".
  • No exclamation marks, no emoji. Errors say what to do next: "Already used by Play next track. Pick another key."

For developers

The popup and the downloads page use React with Tailwind 3. Map the tokens into tailwind.config.js (replace the current band palette; keep exact versions, no new dependencies):

theme: {
  extend: {
    colors: {
      aqua: { 50:'#f1fafc', 100:'#e3f5f9', 200:'#c4e8f1', 300:'#92d4e5', 400:'#52bad6',
              500:'#1da0c3', 600:'#168aa9', 700:'#0f6f8a', 800:'#0b566c' },
      pink: { 100:'#fde8f0', 500:'#e8508a', 700:'#be2f6a' },
      coral: { 100:'#ffe9e2', 500:'#ff7a59', 600:'#e85f3e' },
      ink: { 900:'#12262e', 700:'#2f4650', 500:'#5b7078', 400:'#8197a0' },
    },
    borderRadius: { md: '10px', lg: '12px', xl: '16px' },
    boxShadow: { card: '0 1px 2px rgba(18,38,46,.06), 0 1px 1px rgba(18,38,46,.04)',
                 pop: '0 10px 28px -8px rgba(18,38,46,.18), 0 2px 6px rgba(18,38,46,.06)' },
    fontFamily: { sans: ['"Helvetica Neue"','Helvetica','Arial','sans-serif'] },
  },
}
