# Claude Code — Band Play

@AGENTS.md

## Working rules

- Follow existing project conventions (code style, folder structure, naming, dependency management) unless explicitly instructed otherwise.
- Never refactor unless explicitly requested; apply only the changes directly required for the current request. Keep changes minimal, explicit, and localized.
- Always use a block `if-return` statement (avoid inline one-liners).
- All comments and documentation must be in English; answer in the same language as the question.
- Dependencies: only exact versions, never `^` or `~`. Install with `npm install -E <package>@latest`, then run `npm run check:versions`.
- Do not add attribution lines ("generated by", co-author trailers) to code, docs, release notes, commit messages or pull requests. `.claude/settings.json` turns off Claude Code's own commit and PR attribution.
- Git safety: never run `commit`, `reset`, `rebase`, `push`, `pull --force`, `checkout --force`, `clean`, or `stash drop` unless the user explicitly asks; confirm before `git pull`, `git merge`, or `git stash`. The riskiest commands are also blocked or gated in [.claude/settings.json](.claude/settings.json).

## Agent context

- Rules (`.claude/rules/`) load automatically when matching files are touched: architecture, messaging (messages and ports), Bandcamp DOM selectors and page services, batch download, popup, Firefox, npm versions, docs and CI, testing, agent context.
- Skill `/verify` (`.claude/skills/verify/`): exact versions, format, both builds, ESLint with the type check, `web-ext lint`, unit and e2e tests.
- Skill `/release` (`.claude/skills/release/`, invoked by the user only): version bump, release notes, release commit and zips, then after confirmation push, CI, tag, GitHub Release and the store publish workflows.
- Skills for tests: `/playwright` (`.claude/skills/playwright/`: writing, running and debugging the Playwright suite, Chrome extension specifics) and `/e2e-review` (`.claude/skills/e2e-review/`: the test standard and the review workflow). Tests follow [testing.md](.claude/rules/testing.md).
- Subagents (`.claude/agents/`): `code-reviewer` (read-only review), `qa-engineer` (read-only verification), `e2e-reviewer` (read-only review of tests with `/e2e-review`), plus the generated Playwright agents `playwright-test-planner`, `-generator` and `-healer` (regenerate with `npx playwright init-agents --loop=claude --project=e2e` after a Playwright update; their output must pass `/e2e-review`).
- Plugin `modern-web-guidance` (enabled in `.claude/settings.json`) provides the official `chrome-extensions` skill for Chrome APIs.
- MCP servers (`.mcp.json`): `chrome-devtools` loads the unpacked build into Chrome for in-browser checks; `playwright-test` serves the Playwright test agents. `init-agents` overwrites `.mcp.json`, so re-add `chrome-devtools` after running it.
